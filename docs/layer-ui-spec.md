> 状态：**过稿稿（2026-09-27）**。作者口径："下一层要做进入下一层的加载动画、自身状态栏、装备栏，
> 不同层级信息细节度不同。"

## 1. 什么时候出现过渡

| 时机 | 出不出现 | 备注 |
| --- | --- | --- |
| 同一层里换站（第 5 站 → 第 6 站） | ❌ 不出现 | 只在跨层时出现，否则一局要被打断十几次 |
| **从第 N 层进入第 N+1 层** | ✅ 出现一次 | 一局最多两次（1→2、2→3） |
| 进终房 | ✅ 用同一套，但文案换成"这一程的落点" | 与结算页衔接 |
| 退出/放弃本局 | ❌ | 走现有的确认弹窗 |

**三条硬性要求**（写进实现约束）：

1. **可跳过**：任意键 / 点击立即结束过渡，不惩罚、不二次确认。
2. **时长上限 1.5s**：默认 1.2–1.5s；玩家连点跳过时不得累计延迟。
3. **不阻塞加载**：过渡只是"盖一层"，下一层的地图数据、商店候选、谱面都在后台准备；
   过渡不该被真实加载时间拉长（反过来说：真加载慢时它才需要显示进度）。

## 2. 过渡的三个候选

| # | 做法 | 时长 | 好处 | 代价 | 建议 |
| --- | --- | --- | --- | --- | --- |
| ① | 黑场 + 层名淡入（下方一行小字） | 1.2s | 最省、最"梦核"；深色里只有字 | 信息量为零，像加载而不是换层 | 备选 |
| ② | 层名 + 一句话 + 底部细进度线 | 1.5s | 有呼吸：一句话来自这一层的主题（"灯亮起来了"） | 需要为每层写一句话 | **推荐** |
| ③ | 地图不动，只做推近/位移 + 层名浮出 | 0.8s | 不打断视线 | 存在感弱，容易被误认为卡顿 | 备选 |

第 1 层的一句话、第 2 层的一句话、终房的一句，**各层文案**在第一版里先写死三个常量（Loc key），
将来接进"每章一张表"。

## 3. 自身状态栏

字段与来源（全部来自局内快照 `PortfolioGrowthRunData`，不新建一套账）：

| 字段 | 来源 | 第 1 层 | 第 2 层 | 第 3 层 |
| --- | --- | --- | --- | --- |
| 现金 | `runCash` | ✅ 全 | ✅ 全 | ✅ 全 |
| 层与步 | `layer` / 当前站序号 | ✅ | ✅ | ✅（**深层唯一的位置信息**） |
| 负面状态 | 每层一个（设计稿 §5.3，未接线） | ✅ 名称 | ✅ 名称 | ✅ 名称 |
| 人情 | 升级发放（设计稿 §3.4，未接线） | ✅ 数值 | ✅ 数值 | ➖ 收进册子 |
| 局内等级 | 经验（设计稿 §3.5，未接线） | ✅ 带进度条 | ✅ 只给数字 | ➖ 收进册子 |
| 旅伴 | 本层同行（设计稿 §3.6，未接线） | ✅ 名字 + "本层" | ✅ 名字 | ➖ 收进册子 |
| 生命值 | **不放状态栏** | 逐曲重置，属于演奏页 HUD | | |

排布：一条横向胶囊栏（自动换行，最多两行），**不用图标代替文字**——这是"我自己带的东西"，
不是系统参数。空字段（还没接线的系统）整条不画，不显示"占位"。

## 4. 装备栏

- **8 格**（设计稿 §5.2），一局内不变；满格时拿到新件要**置换或卖掉**（卖出规则仍待拍板）。
- 稀有度沿用价格表：**白 40 / 蓝 80 / 金 160** → 描边颜色按稀有度走（白/蓝/金）。
- **一次性件**（如"备用弦""备用的那把"）用掉后打一个红点，不消失——它是记忆的一部分。
- 点任一格 → **详情卡**：名字 + 一句话 + 来历（设计稿 §4.2 的三种来历） + "白 · 40 · 第 1 层买到"。

| 层 | 装备栏显示 |
| --- | --- |
| 第 1 层 | 格子 + 稀有度描边 + 编号；点开看名字与来历 |
| 第 2 层 | 格子 + 稀有度描边（名字只在详情卡里） |
| 第 3 层 | 统一灰、连稀有度也不显示（东西还是你的，但你不再数它们） |

> 第 3 层那一档在效果图里标了**反例警告**：它会削弱"刚买到好东西"的爽感。若作者觉得太狠，
> 退一档——保留稀有度描边，只把名字收起来。

## 5. 每层信息细节度（总表）

| 界面 | 第 1 层（近） | 第 2 层 | 第 3 层（远） |
| --- | --- | --- | --- |
| 过渡 | 层名 + 一句话 | 同左 | 同左（文案换成"越来越不像你认识的地方"） |
| 状态栏 | 全字段 | 收起来历与进度条 | 只剩 现金 / 层与步 / 负面 |
| 装备栏 | 描边 + 名字 | 只有描边 | 统一灰 |
| 地图 · 下一步 | 类型 + 场景名 | 只给类型 | 只给类型 |
| 地图 · 更远的行 | "？" | "？" | "？" |

理由：与基调一致（"越远越离开现实"），也让**情报类道具**（抄歌本＝本层可见、司机＝下一层可见）
在深层更值钱——信息本身就是这一程的货币之一。
