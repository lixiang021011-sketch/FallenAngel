# FallenAngel 肉鸽第一章设计稿 —— 千禧梦核

> **English summary** — The design baseline for the game's first roguelike chapter, settled with the
> author on 2026-09-23. The chapter's register is **millennium dreamcore** (the Y2K childhood imagery of
> the 2000s), its world is "the city inside your headphones", and its through-line is **a promise and a
> song whose second half the player cannot play yet**. A run is 3 layers / 7 performances; the player
> picks a **musician identity** (drummer / bassist / guitarist) that fixes which chart type they play all
> run, collects **personal gear** (16 items, four of them still to be written) and **instrument-specific
> gear** (3 per identity, each with an α/β direction, levelled by the gear you collect), spends **money**
> on objects and **人情 (favours)** on travelling companions, and each layer carries one single negative
> state. Numbers are sized from a re-run of `balance/balance_sim.py`. Everything in §7 is explicitly not
> decided yet. This document is the design baseline; `docs/architecture.md` stays the code-side contract
> and `docs/roadmap.md` stays the to-do list.

> 状态：**设计拍板**（2026-09-23）。实现未开始，代码侧一个字符都还没动。
> 来源：2026-09-22 ~ 09-23 作者与 AI 的设计讨论；外部参照为《绝区零》零号空洞**现版本**与
> 《明日方舟》集成战略**沉沦者的黑流树海**（均为 2026 年现版本，旧版走格子零号空洞已作废，不作为依据）。

## 1. 基调（尺子）

### 1.1 一句话内核

> 替没能走上那条路的少年，把那条路走一遍——去很远的远方，见很多的人，用双手和耳朵完成这段旅途。

### 1.2 底色与质地

- **底色：美好与惊叹。** 这是本作许诺的那条人生。不写苦难、不写压迫、不写绝望。
- **质地：青涩 / 向往 / 迷茫。**
  - **青涩**——笨拙的真诚。不是笨，是"第一次做"；不掩饰不熟练。
  - **向往**——想往远处去。不是野心，是好奇和心动。
  - **迷茫**——还没找到路。不是绝望，是"还没"。
- 可以有**淡淡的忧伤**，但那是"说不出口"，不是苦。

### 1.3 换重力（不是去重力）

去掉**账单的重力**，换成并加强**人的重力**：

| 去掉 | 换成 |
| --- | --- |
| 房租、工期、交不起车费、社会身份 | 约定、时间、距离、告别、说不出口的话、可能见不到的人 |

**没有重量的世界，向往就没有对象、迷茫也没有来源。** 玩家一路上的每一个决定的重量，都来自
"你答应过一个人"。

### 1.4 基调管什么、不管什么

- **管**：文案的语气、命名的口吻、美术的取舍、音乐怎么被呈现、失败怎么被处理、成长被记成什么样子、界面呼吸的快慢。
- **不管**：玩法规则。基调是**滤镜**，不是要"做出来"的系统。

### 1.5 反面清单（出现即跑偏）

燃、爽、压迫感、恐怖猎奇、精英感、把人写成失败者、把结局写成胜利，以及所有系统术语——
增益、模块、被动、参数，一律不许出现在玩家眼前。

### 1.6 五条尺子（任何内容都过一遍）

1. 这是一个少年**第一次做**的事吗？
2. 它让人更想去远处，还是更想回家？（两种都对，但必须知道是哪种）
3. 它承认不确定吗，还是假装一切都清楚？
4. 它是一个真实的人、真实的东西，还是一个系统术语？
5. 如果它失败了，它让人羞耻，还是让人想再来一次？

### 1.7 元素规则

**物件必须是那个年代的中国孩子真的摸过的东西，空间必须是我们真的待过的地方。**
摸过 / 待过 / 听过——三样里至少占一样，否则不进第一章。

### 1.8 千禧梦核的取用范围

只用**光、空、重复**三样；**不用**诡异、监视、恐怖。
（梦核有两个方向：温柔的空（nostalgia）与诡异的空（uncanny）。后者只允许在"越远越离开现实"的
深处放**一点点**，用来制造**惊叹**，绝不制造恐惧。）

| 组 | 可用元素（示例） | 用在哪 |
| --- | --- | --- |
| 光与质感 | 过曝的午后、荧光灯的绿白、电视屏幕的蓝、水面光斑、CRT 扫描线、VHS 噪点、曝光过度的旧照片 | 演奏界面：判定线可以是电视机的蓝，命中反馈是过曝的光而不是锐利爆发 |
| 空间 | 空无一人的商场中庭、停摆的旋转木马、傍晚的小学操场、没人的泳池、小区健身器材、旧招待所走廊、网吧一排关着的显示器、音像店货架、天桥、地下通道、候车厅、走廊尽头的一扇门 | 地图节点：每一站就是这样的地方，没有人但有人来过的痕迹 |
| 物件 | 翻盖手机、小灵通、复读机、随身听、MP3、CD 盒、磁带、彩铃、贴纸、玻璃珠、钥匙扣、塑料相框、千千静听的频谱、Windows XP 的蓝天、闪动的头像 | 器材与纪念品：不是精致装备，是塑料和贴纸 |
| 声音 | 电视白噪、风扇声、远处广播、楼道回声、拨号音、彩铃、蝉鸣、水声、旧电梯机械声、下课铃 | 过场、加载、结算之间——梦核从来不安静 |
| 人 | 只有背影的人、隔着玻璃的人、看不清脸的人、重复同一个动作的人、坐在长椅上等的人、不属于这个年代的人 | 事件房：不需要正脸，也不需要台词 |

## 2. 世界与主线

### 2.1 世界：耳机里的城市

天桥、地下通道、学校后门、末班公交、河边、琴行门口——都是**玩家真的走过的地方**；戴上耳机、
音乐一响，它们就被改写成别的样子，**越远越不像你认识的地方**。

三件事同时装进去了：**耳机是媒体，路是城市，歌是音乐。** 那句谁都不会说出口的秘密正好装得下：
**"我真正活过的那些时刻，是我戴着耳机的时候。"**

### 2.2 主线（一个约定 + 一首没弹完的曲子）

> 你答应过一个人：等你能把那首曲子弹完，就去找他/她。
> 可那首曲子你只会前半段——后半段你听不懂，也弹不出来，那是要在很远的地方才听得懂的东西。
> 所以你背上琴，出发了。
> 每一程走到哪儿，你就弹到哪儿；你能弹出多少，取决于你走到了哪里。

- **这一程的落点**：你终于把那首曲子弹完的那一天。（那个地方还有没有人在等你，待定。）
- **为什么可以重来**：约定可以有无数次机会。失败不是死，是"这一程没走完"。
- **越远越离开现实**：日常的站像真的，越远的站越奇——因为你正在接近那段你弹不出来的东西。

### 2.3 章节制

主线跨章；每一章换一种青春的形状。

- **第一章：千禧梦核**（本稿）
- **存档**：日系青春、《美高感》（midwest emo 那一支）——留给后续章节，**第一章一个元素都不出现**

### 2.4 文化只留在语感里

不做"日式 / 美式 / 中式青春"的三选一，因为现实细节会把玩家拽回一地鸡毛。
**文化背景体现在语言与情感表达方式上**（含蓄、留白、把话说一半、"不好意思说出口"），
而不是靠便利店 / 加油站 / 筒子楼这类地理符号支撑。

音乐质地保留日式与西式的独立音乐（Humbert Humbert 的气声民谣、Syd Matters 的慢半拍、
midwest emo 的清音琶音）——**一个听着外来音乐长大的少年，写出来的东西当然带着别人的影子**，
这不是漏洞，这是真实。

### 2.5 参考坐标（每引入一部，必须榨出一条可执行的规则）

| 作品 | 它想了什么 | 我们拿走的规则 |
| --- | --- | --- |
| 《看不见的城市》 | 城市是心理结构，不是地理 | **每一站只用一个念头定义** |
| 《奇诺之旅》 | 旅行者只停三天，看、听、走，从不出手 | **玩家不干预别人的生活**：选项不是"救不救"，是"要不要留下" |
| 《银河铁道之夜》 | 同行者会在半路下车 | **旅伴是"同行一段"** |
| 《小王子》 | 你为它花的时间让它变得重要 | **器材的来历＝有人为它花过时间** |
| 《菊次郎的夏天》 | 一次没达成的旅行，什么都没得到却什么都变了 | **允许"没见到那个人"的结局** |
| 《城南旧事》 | 成长＝一次次送别 | **每程记一个离开的人** |
| 《Journey》 | 陌生人短暂的同行就是全部的故事 | **不需要对话系统** |
| 《千与千寻》 | 名字、约定、回程 | **身份＝你在路上成为的那个人** |
| 《社戏》 | 记忆会把辛苦滤成美好 | **册子只写最好的那一个瞬间** |
| 《牧羊少年奇幻之旅》 | 宝藏在出发的地方 | **终房要有"回家"的选项**（不是失败） |
| 汪曾祺 / 沈从文 | 情绪靠物和天气说 | **文案语感的样本** |

## 3. 一局的结构

### 3.1 规模

| 项 | 数值 |
| --- | --- |
| 层 | **3 层** |
| 演奏 | **7 场**（其中 **2 场硬仗**） |
| 节点 | 演奏 7 / 商店 2 / 事件 3 / 休息 2 / 终房 1 = **16 个** |
| 一局时长 | 20–30 分钟（一首曲 2–3 分钟） |

### 3.2 六类节点

左边是内部叫法，玩家看到的是右边的场景名——**不要让玩家看见"商店"这种词**。

| 节点 | 玩家看到的叫法 | 给什么 | 要付什么 |
| --- | --- | --- | --- |
| 演奏房 | 便利店门口、停车场、走廊、天桥下、天台、学校后门、没人的泳池边、商场中庭 | 经验（必有）+ 三选一（60%）/ 钱（25%）/ 无事（15%） | 打这一曲 |
| 硬仗 | 同一个地方，但人多、灯亮 | 三选一，**保证至少一件蓝以上** | 档位高一档；输了路费不退 |
| 商店 | 旧货市场、音像店、小商品市场 | 买器材，**也可以卖**（把不要的换成钱） | 钱；刷新也要钱 |
| 事件房 | —— | 左手 / 右手 / 钱 / **置换** / 一段路 | 情境里的那个选择，好的那条总带代价 |
| 休息房 | 招待所、网吧包夜、候车厅的长椅 | 回状态、清一个负面、翻册子 | 花掉一晚 |
| 终房 | 这一程的落点 | 一件纪念品、结算、记进册子 | —— |

### 3.3 遭遇＝谱面

**玩家遭遇的不是歌曲，是谱面**——一首歌 × 一件乐器 = 一张谱面，这是一个关卡。

- **乐手身份在开局选定**，决定这一整局打什么谱面（类似杀戮尖塔的角色）。
- 键数差异天然由身份承担（鼓 4 键、吉他 5 键，引擎已支持）。
- 同一首歌在一局里出现两次（不同乐器）是自然的。
- "一曲多谱"因此从体验性卖点变成**结构必需**。

### 3.4 两种货币

| 货币 | 用来买 | 来源 |
| --- | --- | --- |
| **钱** | 器材、装备、路费 | 演奏结算、事件 |
| **人情** | **请旅伴**（同行的人） | 探索等级升级 |

"你请人同行是欠人情，人走了这笔账也就清了。"

### 3.5 探索等级（局内）

- **局内轴**：一局内成长，跨局清零（不碰局外成长）。
- **经验只从演奏来**（硬仗给得多，事件给一点）。
- **升级给"人情"**——参考集成战略：等级给的是招募货币，不是容量。
- 于是演奏房"什么都没拿到"的那几场也不寒酸：**你至少长了一级**。

### 3.6 旅伴（见无数的人 → 机制）

| 项 | 规则 |
| --- | --- |
| 怎么来 | 在事件房或休息房遇到人；人情够了就有一条"要不要一起走一段"的选项 |
| 同行多久 | **到本层结束**——进下一层时他就不在了 |
| 占不占包 | **不占**（他是人，不是东西） |
| 怎么走 | 告别时可能留下一件东西（进册子），也可能什么都没留，只是走了 |

第一批旅伴（每人一种助力，短、强、有味道）：

| 人 | 在哪遇到 | 同行期间 | 告别 |
| --- | --- | --- | --- |
| 卖艺的姑娘 | 旧货市场 | 她替你把钱收好：本层每场演奏后多一笔钱 | 留下一张写着歌名的纸 |
| 开货车的司机 | 休息房 | 他告诉你前面是什么：本层剩下的节点对你可见 | 留下一盒磁带 |
| 同样背着琴的少年 | 事件房 | 他跟你合奏：本层每曲第一次断连不清零 | 什么也没留下 |
| 会数拍的老人 | 事件房 | 本层每曲开场判定更准 | 说了一句"你比我当年好" |

**旅伴就是"人形的器材"，但更短、更强、更有味道，而且一定会走。**

## 4. 构筑

### 4.1 三层结构与 v1 取舍

| 层 | 是什么 | v1 |
| --- | --- | --- |
| **左手：随身器材** | 所有乐手都带的通用件，只改演奏本身 | ✅ 做（16 张） |
| **招牌器材：职业件** | 各乐器的专属件，一个身份一套 | ✅ 做（先只做鼓手） |
| 组合件 / 共鸣 | 凑齐触发、跨层组合 | ❌ 第一版砍掉，等跑起来缺中期目标再加 |

**明确砍掉的**：压力条（蚀）式的侵蚀系统、定向件（聚合徽标式）、4/8 共鸣与进阶件——
它们都要么增加理解成本，要么需要更大的卡池。

### 4.2 通用件（左手）：16 张随身器材

**规矩：通用件只改演奏本身，不碰钱。** 钱是装备层的活，两层别抢地盘。

| # | 器材 · 稀有度 | 玩家看到的那句话 | 机制 | 落地 |
| --- | --- | --- | --- | --- |
| 1 | 折叠谱架 · 白 | 晃是晃，摊开就能用。 | 判定线不会被遮蔽 | 现成 |
| 2 | 谱架上的铅笔 · 白 | 你在谱上画了记号：哪里该重，哪里要轻。 | 开曲预览前 8 小节 + 音符标注 | 钩子 |
| 3 | 抄歌本 · 蓝 | 你抄下了这一带会唱的东西。字很丑，但你认得。 | 本层剩余房间可见 | 钩子 |
| 4 | 耳机 · 蓝 | 塞上它，外面就安静了。 | 自己声部与命中更清楚；被遮蔽时靠听也能打 | 钩子 |
| 5 | 摆针节拍器 · 白 | 它比你还稳。 | 早/晚偏差更醒目 | 现成 |
| 6 | 热水袋 · 白 | 手热了才弹得动。 | 开场 30 秒判定更准 | 现成 |
| 7 | 电子节拍器 · 白 | 三连、十六分，它都会打。 | 密集段判定更准 | 钩子 |
| 8 | 耳塞 · 蓝 | 外面的声音没了，只剩你和拍子。 | 判定收紧、Perfect 加分更高 | 现成 |
| 9 | 铁盒里的拨片 · 白 | 盒子里还有一整把。 | 前 3 次误触不计 | 钩子 |
| 10 | 一卷透明胶 · 白 | 什么都能粘。 | 让一个负面失效 | 钩子 |
| 11 | 备用弦 · 蓝 | 断了一根，你还弹得下去。 | 第一次断连不清零 | 钩子 |
| 12 | 喉糖 · 白 | 唱完一颗。 | 每次演奏结束回血 | 现成 |
| 13 | 创可贴 · 白 | 手破了，贴上继续。 | 受伤减少 | 现成 |
| 14 | 旧收音机的旋钮 · 金 | 拧到哪儿，就停在那儿。 | 自己推判定窗口，推完这一曲定住 | 钩子 |
| 15 | 备用的那把 · 金 | 你还有另一把。 | 本曲失败可原地再来一次 | 钩子 |
| 16 | 复读机 · 蓝 | 本来是拿来学英语的。 | 单次手滑自动吸附到正确的音符（范围与次数有限） | 钩子 |

稀有度分布：**白 9 / 蓝 5 / 金 2**。卡池目标 20 张，还差 4 张（留到以后扩章节时补）。

**来历**（每件一句，可以三种）：别人给的（`摆针节拍器 · 旧货市场的老人给的`）／家里带的
（`热水袋 · 出门时塞进包里的`）／想不起来哪来的（`铁盒里的拨片 · 不知道什么时候放进去的`）。

### 4.3 招牌器材（职业件）

**形状**：

- 每个身份 **3 件**，都是那件乐器的**招牌器材**；
- 每件有 **α / β 两个方向**，选了就定，这一程不能反悔；
- **靠通用件喂养升级**：每捡到 2 件通用件 +1 级，最高 4 级；
- v1 **先只做鼓手**（只有鼓谱有真谱可测；贝斯与吉他各一张谱都还没有）。

**一条硬规则：职业件的机制，必须来自这件器材在现实中真的做的事。**
（反面教材：把"镲片"绑到"连打"上——那是从谱面反推器材，牵强。）

鼓手三件：

| 招牌器材 | 它在现实里做什么 | α 方向 | β 方向 |
| --- | --- | --- | --- |
| **专用耳返** | 监听混音：把自己的声部推上来、别的压下去 | 「只留自己」：其他声部压到最低，更专注但听不见别人 | 「留一点别人」：别的声部留一部分，合奏感更足但更杂 |
| **自动鼓机** | 一台真的会替你打鼓的机器 | 「替你打」：连续 Miss 到阈值后接管一段，连击恢复，但这段不计分 | 「跟你打」：同样接管，且计分，但触发门槛更高 |
| **地毯** | 垫在鼓组底下，防滑防震 | 「钉死」：环境与状态带来的干扰（走神、手冷）对你无效 | （β 方向待定） |

> 耳返的**技术前提**：现在谱面只有一个 `audioFileName`，**没有分轨**。短期用滤波近似
> （给自己的声部频段加权），长期再升级到真分轨。
> 自动鼓机有现成底子：判定簇里本来就有 AutoPlay 的实现，改成"只在一段内启用"即可。

### 4.4 转职卡：「一把借来的琴」

- 你在路上遇到另一个乐手，他把琴借给你。**你换到那个位置上**，这一程剩下的谱面都变成那件乐器的。
- **随身器材留着**（那是你自己的习惯，走哪带哪），**招牌器材封存**（鼓手那三件暂时用不上，
  转回来还能接着用）。
- **代价不用"判定更严"来表达**：代价是换过去之后的一两曲**你手上是空的**（没有职业件可用），
  而且**你回不去**——除非再遇到一把借来的琴。
- 文案：「他说，你试试。」

### 4.5 右手：纪念品与册子

- 不改玩法，只进**册子**：票根、照片、别人塞给你的电话号码、雨里捡的一块石头、写了一半的信、
  别人留下的一盒磁带。
- 每一程结束记**一个离开的人**、**最好的那一个瞬间**（记忆会自动过滤掉辛苦）。
- 册子是这一章最便宜也最动人的东西：一行文字加一个小图标。

### 4.6 "自动覆盖玩家的错误操作"的三层分工

| 层次 | 管什么 | 归谁 |
| --- | --- | --- |
| 校准 / 建议偏移 | 整段的系统性偏早或偏晚 | **设置里，免费，人人有**（`HitErrorTracker` 已经在测） |
| 复读机 | 单次手滑、抢错音符 | **通用件，要买** |
| 职业件的释放效果 | 局部、短时间内的自动命中 | 鼓手「踩锤」→ 现在是「自动鼓机」的 β 方向 |

**不做成全局默认**：全局默认等于"人人自动对准"，技术表达被稀释；做成可购买的一件东西，
它就落进设计语言里的"降风险"，由玩家自己选择。

三种错法对应的实现（代码侧参考）：

| 玩家犯的错 | 机制 | 落在哪里 |
| --- | --- | --- |
| 整段抢拍 / 掉拍 | **弹性判定基准**（只在判定侧加缓动偏移，**不能动 `SongTime`**） | `HitErrorTracker` 的测量结果接过来 |
| 单次手滑 | **输入时间吸附**（把输入的音乐时间戳吸附到容差内最近的待判音符；**窗口表一个字不改**） | 输入装配处或候选归属 |
| 抢到别的音符 | **归属修正**（取离输入最近的候选；现有的"同指去重、更优结果可顶掉"扩一点） | `LiveJudgeCore` 候选分配 / 同指去重 |

两条实现要点：**吸附必须设上限**（否则等于替我打）；**原始时间要留一份**（早/晚指示与命中误差统计要用）。

## 5. 节奏与奖励

### 5.1 奖励给法（参考集成战略：作战类节点只是少数）

| 节点 | 给什么 | 比例 |
| --- | --- | --- |
| 演奏房（普通） | 三选一（左手器材） | 约 60% |
|  | 给钱 | 约 25% |
|  | 什么都不给（就当歇了一场） | 约 15% |
| 硬仗 | 三选一，保证至少一件蓝以上 | 100% |
| 事件房 | 左手 / 右手 / 钱 / **置换** | 按事件写 |
| 商店 | 买 2–3 件，**也可以卖** | —— |
| 休息房 | 回状态、清一个负面、翻册子 | —— |
| 终房 | 一件纪念品 + 结算 | —— |

### 5.2 包

- **8 格**（6 格装不下 7 场演奏的产出，10 格又太宽）。
- 满了要拿新的，就得**留下一件**；优先解是**卖掉或置换**（丢弃是被迫选项，不是第一选项）。

### 5.3 负面（旅途的代价）

**每层一个状态**（**不设压力条**），来自事件房选贵的那条与硬仗失手，在休息房清掉一个；
「一卷透明胶」可以临时挡一次。

四种，刻意**都不用判定窗口当杠杆**：

| 负面 | 效果 |
| --- | --- |
| 手冷 | 开场 30 秒不加成 |
| 走神 | 连击加成上限减半 |
| 想家 | 本曲结算少一档钱 |
| 怯场 | 本曲招牌器材不生效（你的家伙没带来） |

### 5.4 难度

**只写 3 档（第 1 / 2 / 3 层），每档一行具体规则 + 一个倍率**（写法照抄集成战略的"每档一条规则"
而不是一个模糊的滑块）。

## 8. 实现顺序（建议）

**第一切片：6 张现成 + 3 个最值的钩子**

| 批次 | 内容 | 为什么先做 |
| --- | --- | --- |
| ① 现成 6 张 | 折叠谱架、摆针节拍器、热水袋、耳塞、喉糖、创可贴 | 不写新代码就能进游戏 |
| ② 钩子：连击保护 | 备用弦（第一次断连不清零） | 代表"手感的保护" |
| ③ 钩子：失败重试 | 备用的那把（本曲失败原地再来） | 代表"失败的兜底" |
| ④ 钩子：密集段 | 电子节拍器（密集段判定更准） | 代表"节奏本身"，且这套网格底子后面四张卡共用 |

**纪律照旧**：只改 `Assets/Scripts` 下的 `.cs`；场景 / 预制体走 SceneBuilder 重建；
文档改动先问；一次一个可编译、可验证的改动；每步跑对应自检组 + 带路径提交。
