# 谱面编辑器使用说明（Chart Editor）

> 面向 5 轨 v2 协议（`metadata.formatVersion = 2`）。当前是工程内 EditorWindow 版本，随 Unity 工程使用。
> 参照 PhiEdit / OpenChart 的编辑交互设计；差异与未实现项见文末对照表。

## 1. 打开与存读

- 打开：Unity 菜单 **Tools > FallenAngel > Chart Editor**。
- 默认路径：`Assets/Resources/Charts/chart_editor_draft.json`（可在顶部路径栏改成任意工程内路径）。
- **载入**：读取该路径的谱面；v1（4 轨）谱会提示"保存时按 5 轨 v2 写回"。
- **新建 5 轨**：创建空谱（BPM 140、`formatVersion=2`）。
- **保存 v2**：按 v2 协议写出 JSON（字符串类型 + direction + path + wide + noteCounts），并刷新 AssetDatabase。
- 保存后游戏侧 `ChartLoader.LoadFromResources("chart_editor_draft")` 即可加载（Resources 下不要带 `.json` 后缀调用）。

## 2. 界面分区

| 区域 | 内容 |
| --- | --- |
| 顶部 | 谱面路径、载入 / 新建 / 保存 |
| 元数据行 | 曲名、BPM、偏移(s)、音频文件名 |
| 工具条 | 放置类型、flick 方向、时长(拍)、slide 终点轨、wide、吸附、缩放 |
| 时间轴 | 横轴时间（秒）、纵轴 5 条轨道；滚轮滚动，缩放 80–600 px/s |
| 底部 | 删除选中 / 清空、音符计数、当前时间、实时校验结果 |

## 3. 鼠标与键盘操作

| 操作 | 效果 |
| --- | --- |
| 左键点空白 | 在当前轨道、吸附后的时间点放置所选类型音符 |
| 左键点音符 | 选中（高亮外框） |
| **左键拖动音符中部** | **移动**：左右改时间（自动吸附），上下可换轨；slide 会整体平移路径 |
| **左键拖动音符右边缘**（约 10px 内） | **缩放时长**：仅 hold / slide 有效；拖动时同步更新 slide 路径终点 t |
| 右键点音符 | 删除 |
| 滚轮 | 时间轴滚动（每次 0.5s） |
| 删除选中 / 清空 | 底部按钮 |

> 拖动中的音符会在松手时重新排序；选中项按对象重新定位，不会跳到别的音符上。

## 4. 音符类型与放置参数

| 类型 | 放置参数 | 写入 JSON |
| --- | --- | --- |
| tap | wide 开关（全宽底鼓） | `type:"tap"`，`wide` |
| hold | 时长(拍) | `type:"hold"`，`duration` |
| drag | — | `type:"drag"`（碰即 Perfect，永不 MISS） |
| flick | 方向 ↑/↓ | `type:"flick"`，`direction:"up"/"down"` |
| slide | 时长(拍) + 终点轨(0–4) | `type:"slide"`，`path:[{t:0,x:起点},{t:duration,x:终点}]` |

滑条的 `x` 是连续轨道坐标：0 = 第 1 轨中心，4 = 第 5 轨中心；跨轨滑条是"起点到终点平滑过渡"的数据形态（渲染与判定跟随见"下一步"）。

## 5. 吸附与网格

- 吸附在 **1/4 → 1/8 → 1/16 → 关**之间循环（BPM 取自元数据行，BPM ≤ 0 时自动不吸附）。
- 拍线：每拍一条细线，每 4 拍加重的粗线；网格随缩放自动稀疏。

## 6. 内置校验

保存前后都会实时提示（底部黄色警告框）：

1. 同轨同刻重复音；
2. 同刻超过 2 音（协议上限：多音一律压缩 ≤2 轨）；
3. hold / slide 时长必须大于 0。

校验通过时显示绿色说明。出现警告不阻止保存（便于中途存草稿）。

## 7. 与 PhiEdit 的功能对照

| 能力 | PhiEdit | 本编辑器 | 说明 |
| --- | --- | --- | --- |
| 时间轴 + 音频波形 | 有 | **缺（下一步）** | 需要读音频采样画波形 |
| 试听 / 变速播放 | 有 | **缺（下一步）** | 光标处试听 + 倍速 |
| "从此处试打" | 有 | **缺（下一步）** | 把编辑光标时间传给 `GameManager` 进 Play |
| 放置 / 选择 / 删除音符 | 有 | 有 | 左键放置与选中、右键删除 |
| 拖动移动音符 | 有 | 有 | 中部拖动，可跨轨 |
| 拖动缩放时长 | 有 | 有 | 右边缘 10px 热区 |
| 框选多选 / 批量移动 | 有 | **缺（下一步）** | 需要框选与多选状态 |
| 复制 / 粘贴 / 撤销重做 | 有 | **缺（下一步）** | 需要命令栈 |
| 吸附与网格 | 有 | 有 | 1/4、1/8、1/16、关 |
| 音符类型 | tap/drag/hold/flick（判定线体系） | tap/hold/drag/flick/slide + wide | 本作是**5 轨模型**，没有判定线 |
| 判定线事件动画（moveX/alpha/rotate/speed…） | 有（核心） | **不适用** | 5 轨模型没有判定线；差异谱靠轨道密度与类型表达 |
| 多难度 / 谱面元数据 | 有 | 有 | 曲名/BPM/偏移/音频/难度/等级 |
| 实时校验 | 部分 | 有 | 同轨重复、同刻 ≤2 音、时长有效性 |
| BPM 变速事件 | 有 | **缺（下一步）** | `events` 通道已保留，编辑器暂未提供编辑入口 |

**模型差异提醒**：PhiEdit 是"判定线 + 事件"的 Phi 体系，本作是"固定 5 轨 + 双指可打"的 pjsk 式体系。所以判定线事件那一整类能力在这里不适用；反过来，本作的 `wide` 底鼓（全宽判定）与跨轨 `slide` 路径在 PhiEdit 里也没有对应物。

## 8. 下一步（按优先级）

1. 音频波形 + 光标处试听（含倍速）；
2. "从此处试打"：把光标时间注入 `GameManager` 后直接 Play；
3. 框选多选 + 批量移动 / 复制粘贴 + 撤销重做；
4. BPM 变速事件编辑（`events` 通道）；
5. slide 路径点编辑（现在是起点→终点直线插值，后续支持中间点与曲线）。
