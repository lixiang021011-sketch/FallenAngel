## 1. 游戏概述

FallenAngel 是一款 **4K 下落式节奏音游**（demo 阶段）。

- **当前形态**：单曲 demo。音符沿 4 条轨道下落，到达判定线时击打，系统按时间差判定并计分，曲终结算评级。
- **愿景形态**：**roguelike 音游**——在多曲目基础上，局内随机获取 buff / debuff，动态改变核心玩法（判定线消失、判定窗口缩放、谱面隐身、清屏等），形成"每局不同"的挑战。
- 竖屏设计（1080×1920 参考分辨率），同时支持手机触屏与 PC 键盘。

## 3. 核心玩法

### 3.1 基本规则
- **4 条轨道**（Lane 0~3），音符沿轨道下落，抵达屏幕下方判定线时按键/触屏击打。
- 判定按"击打时刻 - 音符时刻"的时间差（见 3.2）。
- **音符类型**：
  - 普通音符（Normal）：单击。
  - 长按音符（LongStart + LongEnd）：头部按下后需按住至尾部结束，松开时按释放时点判定。
- 空按（无音符可判）与过早/过晚击打不产生判定，音符超窗未击中自动 Miss。

### 3.2 判定与计分

判定窗口（毫秒，`JudgeDefine.cs` 中配置；2026-08-16 参考 Phigros 手感对齐）：

| 判定 | 窗口 | 基础分 | 连击 |
| --- | --- | --- | --- |
| PERFECT | ±80ms | 300 | 保持 |
| GREAT | ±160ms | 200（≈Perfect 65%，对应 Phigros Good） | 保持 |
| GOOD | ±180ms | 0 | **断** |
| BAD | ±200ms | 0 | **断** |
| MISS | 超过窗口 / 未击中 | 0 | 断 |

Phigros 参考值：Perfect ±80 / Good ±160 / Bad ±180 / 之外 Miss；Good 保持连击、Bad 断连击给 0 分。

- 长按得分 ×1.5；长按释放判定不低于 GOOD（BAD 按 GOOD 计）。
- **早/晚指示**（Phigros 手感）：判定偏差 |Δt| > 40ms 时，判定文本下方显示"早"（蓝 #03aaf9）/"晚"（橙 #ff4612）；≤40ms 为 Perfect(Max) 不显示。帮助玩家校准手感。
- **节拍校准**：菜单"节拍校准"→ 16 声滴答测试测量点击延迟 → 推荐偏移（+ = 音符推迟，补偿设备音频延迟）→ ±5ms 微调；全局持久化（PlayerPrefs），叠加于谱面 offset 之上。
- **触点涟漪**：每次按下在实际触摸位置生成扩散淡出的涟漪（Phigros 同款输入反馈）。
- **连击加成**：`基础分 × (combo/100 截断到 1 × 20%)`，即 100 连击时封顶 +20%。
- **准确率** = 加权和 ÷ 判定总数（P/G/G/B/M 权重 100/65/0/0/0）。
- **评级**：S（0 Miss 且 Perfect 数过半）/ A（acc≥95）/ B（≥85）/ C（≥70）/ D。
- 结算页展示 FC（全连）与 PM（全 Perfect）标记。

### 3.3 游戏流程（状态机）

```
Menu ──开始──> Loading ──3-2-1-GO 倒计时──> Playing <──暂停/继续──> Paused
  ▲                                          │
  └─────────────返回菜单（ESC/结算BACK）      └──曲终/重试──> Result ──重试──> Loading
```

状态机由 `GameManager` 统一管理，状态切换通过 `OnStateChanged` 事件广播（见架构约定 §4）。

## 5. 内容与数据

### 5.1 谱面 JSON 格式

存放于 `Assets/Resources/Charts/*.json.bytes`，经 `JsonUtility` 反序列化（注意：字段必须 public 且与 `ChartData` 结构一致）：

```json
{
  "metadata": {
    "songName": "堕落天使 - Demo",
    "songArtist": "FallenAngel Team",
    "chartAuthor": "AutoGenerated",
    "difficulty": 1,          // 0=Easy 1=Normal 2=Hard 3=Expert
    "level": 7,               // 等级 1-20
    "bpm": 140,
    "offset": 0,              // 音频偏移（秒），用于谱面对齐
    "audioFileName": "demo_song",
    "previewStartTime": 10,
    "previewDuration": 15
  },
  "notes": [
    { "lane": 0, "time": 2.0, "type": 0, "duration": 0, "longNoteId": -1 },
    { "lane": 1, "time": 4.0, "type": 2, "duration": 1.2, "longNoteId": 0 }
  ]
}
```

- `type`：0=Normal，1=LongStart，2=LongBody，3=LongEnd。LongEnd 由 LongStart 的 `time+duration` 推导，`longNoteId` 配对头尾。
- 音频放 `Assets/Resources/Audio/`，文件名对应 `metadata.audioFileName`。
- 当前 demo 按钮使用 `ChartLoader.GenerateDemoChart()` 程序生成谱面（四段式：单键练习 / 双键组合 / 长按 / 十六分连打）；`Resources/Charts/demo_chart.json.bytes` 为手动谱面，可由 `GameStarter.StartChartFromResources("demo_chart")` 加载。

### 5.2 场景与预制体（重要）

- **工程不保存任何 `.unity` 场景文件**。场景结构由编辑器工具一键生成：
  - `Tools > FallenAngel > Build Default Game Scene`：重建完整场景（EventSystem、管理器、Canvas、UI 层级）。
  - `Tools > FallenAngel > Create Note Prefab`：生成 `Assets/Prefabs/Note.prefab` 并自动赋给场景中的 NoteSpawner。
- 新建/重装工程后，按顺序执行上述两个菜单即可恢复可玩状态。

## 6. 运行与调试

1. 打开工程 →（无场景时）菜单 `Tools > FallenAngel > Build Default Game Scene` → `Create Note Prefab`。
2. Play → 菜单点 START DEMO（或在 `GameStarter` 勾选 `Auto Start Demo On Awake` 自动开跑）。
3. 编译自查：关闭 Unity 编辑器后执行 `./compile_check.sh`。
4. 运行日志在 `Logs/`；关键状态均有 `Debug.Log`（带 `[类名]` 前缀）。
