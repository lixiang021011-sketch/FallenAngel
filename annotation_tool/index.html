Add a song

One file becomes the master (name it master / mix, or it is the only file). The rest become stems by keyword: guitar, bass, drums, piano, vocal, strings, synth.

    Add many songs (one file = one song)

    For listening through a whole library: pick a folder or a pile of tracks from your phone's storage, and each file becomes its own song. Full mix only — no stems, so review will not offer stem solo for these.

    No audio handy? Generate a short synthesized 4-stem demo song, or load it from demo/manifest.json if the generator has already been run.

    Attach Workbench analysis (JSON)

    Workbench computes timing, sections and boundaries offline; this is where the annotator reads them. The file is matched to a song by its songId (or by title when that matches nothing). Bar and beat are attached to new events as derived information — machine results are never written as annotations.
